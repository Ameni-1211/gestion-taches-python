# Application Python de Gestion des Tâches

## Fonctionnalités

- Ajouter une tâche (avec vérification du titre non vide)
- Afficher toutes les tâches numérotées
- Rechercher une tâche par mot-clé
- Menu interactif en console

## Étapes d'exécution

1. Ouvrir le dossier du projet dans **VS Code**
2. Lancer le programme via le bouton **« Run Python File »** de VS Code ou via la console en tapant
